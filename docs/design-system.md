# Дизайн-система Модус.Отклик

Все значения - в `frontend/src/design/tokens.css`. Этот файл - краткая выжимка для разработчиков, в интерфейсе ее нет.

## Принципы

1. **Нейтральная основа.** Текст и поверхности берутся из одной серой шкалы. Цвет на экране - исключение, а не фон.
2. **У цвета три языка.** Действие - синий акцент: главная кнопка, ссылка, фокус, выбранный пункт. Этап обращения - своя шкала: у статуса один цвет в точке, на шкале этапов, на плитке типа и в аналитике. Роль человека - холодные цвета только на аватаре и значке роли.
3. **Цвет не работает один.** Красный, янтарный и зеленый сообщают состояние: отказ и просрочка, ждем человека, сделано. Рядом всегда стоит слово или значок. Сплошная заливка - только у метки «просрочено».
4. **Иерархия шрифтом.** Важность показывают размер, насыщенность и отступы. Рамки и цвет для этого не используются.
5. **Размеры из шкал.** Размеры шрифта, отступы, скругления и высоты элементов берутся из токенов. Отступления известны (подписи 10-11px, скругление 12px у меню, крупное число в аналитике) и новые не добавляются.
6. **Одно состояние - одно название.** Подписи статусов приходят с сервера; шкала этапов, точки, вкладки и аналитика используют только их. Автору вместо «Ожидает уточнения» показывается «Нужен ваш ответ» - единственное исключение. Кнопки называют действие, а не состояние.

## Цвет

**Нейтральная шкала**

| Токен | Где |
|---|---|
| `--n-0` | карточки |
| `--n-25` | вложенный блок |
| `--n-50` | фон страницы |
| `--n-100` | плашки |
| `--n-150` | разделители |
| `--n-200` | дорожки |
| `--n-300` | границы полей |
| `--n-400` | неактивное |
| `--n-500` | подписи |
| `--n-600` | вторичный текст |
| `--n-700` | текст статуса |
| `--n-800` | счетчики |
| `--n-900` | основной текст |

**Акцент:** `--a-50` наведение, `--a-100` мягкий фон, `--a-200` ореол поля в фокусе, `--a-500` акцент и кольцо фокуса, `--a-600` наведение на кнопку, `--a-700` текст на мягком фоне.

**Состояния:** `--danger-solid` (точка: отказ; метка: просрочено), `--danger-text`; `--warning-solid` (точка и значок: нужно решить), `--warning-text`; `--success-solid` (точка: сделано), `--success-text`.

**Этапы обращения:** `--stage-1` Новое, `--stage-2` На рассмотрении, `--stage-3` В работе, `--stage-4` Реализовано, `--stage-wait` Ожидает уточнения. Подписи берутся из `meta.statuses`.

**Метки сроков:** `--overdue-bg` (просрочено), `--waiting-bg` и `--waiting-ink` (без ответа).

**Роли:** `--role-*-solid` - холодная часть спектра, где нет цветов состояния. Только на аватаре и значке роли (сотрудник, руководитель, директор, администратор).

## Типографика

Inter, шесть ступеней, других размеров нет.

| Ступень | Токен | Размер / строка · вес |
|---|---|---|
| Заголовок страницы | `display` | 28 / 34 · 650 |
| Заголовок объекта | `title` | 22 / 28 · 650 |
| Заголовок блока | `heading` | 16 / 24 · 600 |
| Основной текст | `body` | 15 / 23 · 400 |
| Подпись | `small` | 13 / 19 · 400 |
| Надпись | `caption` | 12 / 16 · 500 |

На телефоне `display` 24/30, `title` 20/26.

## Отступы и скругления

Шаг отступов - 4px: `--s-1` 4, `--s-2` 8, `--s-3` 12, `--s-4` 16, `--s-5` 20, `--s-6` 24, `--s-8` 32, `--s-10` 40, `--s-12` 48.

Скругления: `--r-xs` метки, `--r-sm` малые кнопки, `--r-md` кнопки и поля, `--r-lg` карточки, `--r-xl` окна.

## Компоненты

- **Кнопки.** На экране одна главная (`btn primary`). Остальные - обычные (`btn`) или без рамки (`btn ghost`); `btn danger` для отказа, `btn icon` для значка. Размеры `lg`, обычный, `sm`. Фокус с клавиатуры - кольцо акцентного цвета.
- **Статусы и метки.** У статуса один цвет на всех экранах, рядом с точкой всегда слово (`StatusPill`, `Status`, `Overdue`).
- **Списки обращений.** Одна поверхность с разделителями (`card rows` + `AppealItem`), а не отдельные карточки.
- **Сообщения.** Фон нейтральный, смысл несет значок (`note`, `note green`, `note amber`).
